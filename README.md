# CampusAssist — Streamlit edition

A student-facing specialization registration guidance prototype. It includes a registration form, illustrative eligibility checks, a TF-IDF/cosine-similarity FAQ chatbot, course descriptions, and a downloadable CSV summary.

## Deploy on Streamlit Community Cloud
1. Extract this ZIP on your computer.
2. Create a GitHub repository (for easiest sharing, set it to Public).
3. Upload `streamlit_app.py` and `requirements.txt` to the repository root.
4. Visit https://share.streamlit.io/ and sign in with GitHub.
5. Choose **Create app**, select the repository and branch, set the main file path to `streamlit_app.py`, then deploy.

## Important scope note
This is a project demo, not a live university registration system. CGPA and credit requirements are illustrative and must be replaced with verified institutional policy. The app does not connect to a college portal or database. Registration details stay in the active app session; a user may explicitly download their own eligibility summary as CSV. Do not enter real sensitive student information into a public demo.
